## 版本 A · 中文详细版

```text
请为下面这个智能家居产品家族生成一组工业设计 3D 渲染效果图。

【产品家族】冰箱菇——贴在冰箱上的语音记账"蘑菇家族"三件套。
【设计语言】圆润蘑菇造型、家族化设计；配色：暖橙 #E85513 + 奶油白 #FFF8F2，
浅木色细节点缀；哑光亲肤软胶质感；全部无屏幕、无多余按键，极简可爱但不幼稚；
仅基座侧面有极小的 "fridgegu" 字样。

【1. 基座（平板 + 大蘑菇 + 小蘑菇位）】
- 圆角扁平卵石形平板，约 120×80×18mm，哑光奶油白，可贴在冰箱旁的墙面
- 左侧嵌一颗大蘑菇实体按钮：蘑菇帽直径约 45mm，暖橙哑光软胶，帽顶微弧，
  帽檐一圈细白描边，可"拍击"（按下录音）
- 右侧一个小凹槽 dock：小蘑菇吸附其上，dock 内 2 个镀金充电触点
- 平板正面下部：细密点阵扬声器开孔 + 一个隐藏麦克风孔；底部 USB-C

【2. 小蘑菇（录音豆）】
- 手掌心大小，总高约 40mm，蘑菇帽直径约 38mm，暖橙哑光帽 + 奶油白软胶柄
- 柄部下端一个近讲麦克风小孔，底部平整（充电触点），可单手拿起

【3. 超小蘑菇（单件门磁传感器）×N】
- 直径约 25mm、高约 10mm 的迷你蘑菇贴片，暖橙帽 + 白色底座，内置纽扣电池
- 分贴在冰箱门边缘和抽屉门上

【场景与氛围】现代明亮厨房，原木 + 白色橱柜，暖色晨光，浅景深，
类小米生态链产品摄影风格，photorealistic，soft studio lighting，8k。

【出图清单】
- 图1 全家福：基座贴墙、小蘑菇在 dock 上、3 颗超小蘑菇分别贴在冰箱门和抽屉
- 图2 基座 45° 特写：大蘑菇按钮 + dock 充电触点细节
- 图3 人手持小蘑菇对着打开的冰箱说话（近讲场景）
- 图4 超小蘑菇贴在抽屉门上的微距特写
```

## 出图后怎么用

- 全家福 → 作业文档"效果证据"+ 展示软件概览页配图
- 基座特写 → 公众号推文封面候选
- 手持场景 → 演示视频封面
- 注意：效果图是**外观构想**，不代表已开模/已打样；作业与公众号使用时按实情标注"设计渲染图"。
