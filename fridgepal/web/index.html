一套贴在冰箱上的"蘑菇家族"

拍大蘑菇随手记 · 开门它主动问 · 拿走小蘑菇边放边记 —— AI 整理成库存，微信卡片交付。

大蘑菇 · 基座

贴在冰箱旁的无屏平板。大蘑菇按钮可以拍：拍一下开始录音，再拍结束。内置广域麦克风和喇叭——门开时它主动问"拿了什么？"，也是全系统的 Wi-Fi / 蓝牙网关。

小蘑菇 · 录音豆

平时吸附在基座上充电待机；取下即录、放回即传。近讲收音，边放边说，录音先存本地缓存，回传成功才清空——不怕撑爆。

超小蘑菇 · 单件门磁

贴在冰箱门和抽屉上的单件传感器（不是两件套门窗磁）。加速度唤醒+姿态判定感知开关，蓝牙上报，纽扣电池目标用 3 年。无线方案对标小米人体传感器 2S。

一条云链路，三个录音入口

拍键 / 门开 / 取下小蘑菇→ 录音→ 百炼 ASR（热词）→ 替换规则→ DeepSeek 提取→ 库存更新→ 公众号表格卡片

仲裁铁律：同一时刻只有一个录音+识别在跑，冲突时小蘑菇 > 大蘑菇。无屏幕，一切结果走微信卡片。

这个演示页是什么

这是冰箱菇的展示软件：介绍产品外观与系统，同时真实演示云端链路—— 在「语音记账」页录一段"放了两盒牛奶"，就能看到 语音 → 识别 → 提取 → 库存卡片 的全过程。 硬件（基座/小蘑菇/超小蘑菇）的选型、BOM 与功耗设计见项目硬件文档。
