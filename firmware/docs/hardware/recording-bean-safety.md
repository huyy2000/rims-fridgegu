# 录音豆 v0 · 硬件安全文档（ESP32-C3 SuperMini）

> 2026-10-01 修订：修正 MAX98357A SD 脚、AH3144 供电、霍尔触发沿三处错误（对照数据手册）。
> 产品形态已升级为"冰箱菇"三件套（`docs/hardware/冰箱菇-硬件总览.md`）；本文的 I2S/BOOT/电源事实对小蘑菇与基座仍然适用，保留作 C3 参考底稿。

> 改固件前必读。改引脚必须同步 `main/platform/board_pins.h` + `host_test/board_pins_tests.cpp` + 本文档。

## 芯片事实（ESP32-C3，不可协商）

| 资源 | 引脚 | 说明 |
|------|------|------|
| Flash (SPI) | GPIO11~17 | **被 Flash 占用，禁止接任何外设** |
| BOOT 键 | GPIO9 | 下载模式：按住 BOOT 再上电/复位（SuperMini 板载 BOOT+RST 键） |
| 板载 LED | GPIO8 | SuperMini 出厂接法 |
| 原生 USB | GPIO18/19 | 烧录与日志主通道 |
| Strapping 脚 | GPIO2 / 8 / 9 | **上电瞬间的电平决定启动模式**；不许接上电时被强行拉低的器件 |

## 录音豆 v0 引脚分配

| 功能 | 引脚 | 电气说明 |
|------|------|---------|
| 录音键 | GPIO0 | 低有效，内部上拉，下降沿中断；PCB 长走线建议加 100nF 去抖电容 |
| 霍尔/门磁 | GPIO1 | ⚠️ AH3144 供电范围 **4.5~24V，3.3V 出规格**（绝对下限约 3.5V）——要么换 3.3V 兼容霍尔型号，要么供 5V（输出开漏，上拉到 3.3V 保证逻辑安全）；v4 形态已改用加速度计方案，此行仅作参考 |
| I2S 麦 INMP441 | SCK=GPIO4, WS=GPIO5, SD=GPIO6 | 3V3 供电，L/R 接 GND（左声道） |
| I2S 喇叭 MAX98357A | BCLK=GPIO3, LRC=GPIO10, DIN=GPIO7 | 5V 或 3V3 供电；SD 脚电平决定模式（数据手册）：**<0.16V=关断，0.16~0.77V=(L+R)/2 单声道混音（推荐），0.77~1.4V=右声道，>1.4V=左声道**。单喇叭接分压到 (L+R)/2；**接 GND=关断，永远无声** |
| 状态 LED | GPIO8 | 板载，不外接 |
| 电源 | TP4056 + 1S 锂电 + USB-C | 充电时系统由 USB 供电；电池经 LDO 3V3 给模组。**若保留霍尔方案需另设 5V 轨（AH3144 下限 4.5V），3.3V 轨带不动** |
| Flash 容量 | ⚠️ C3 SuperMini 市售常见 **4MB**（不是 16MB） | 录音缓存写 Flash 的时长上限 =（4MB−固件/分区）÷ 码率；ADPCM ~8KB/s 时约 6~7 分钟。MVP 限单条录音 ≤60s；采购时确认实际容量 |

## 红线清单

1. **GPIO11~17 一根线都不要接。** 接了轻则启动失败，重则 Flash 总线被干扰、固件反复重启。
2. **GPIO2/8/9 上电瞬间必须保持正常 strapping 电平**：外设选型时避开这三脚（录音键/霍尔已避开，见守卫测试第 4 条）。
3. INMP441 与 MAX98357A 的麦克风/喇叭地线要**单点汇到电源地**，避免 I2S 地弹带来爆音。
4. 霍尔上拉电阻不可省——AH3144 是开漏输出，无上拉则 GPIO1 永远悬空；触发沿与磁铁极性绑定：磁铁装门框、门开=磁场消失=输出释放=引脚被上拉拉高=**上升沿**才是"开门"事件（旧文档写下降沿是错的，下降沿是关门）。
5. 锂电充电电路首版必须加保护板（1S 过充过放保护），TP4056 裸板不带保护。
6. 下载模式：**按住 BOOT 点一下 RST 再松开 BOOT**；正常退出直接重新上电。
